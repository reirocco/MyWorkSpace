# 📓 Guida Markdown: Visualizzazione vs Codice

Questa tabella ti mostra l'effetto visivo a sinistra e i comandi esatti da digitare a destra.

## ✍️ Formattazione Testo
| Visualizzazione (Risultato) | Scrittura (Cosa digitare) |
| :--- | :--- |
| **Grassetto** | `**Grassetto**` |
| *Corsivo* | `*Corsivo*` |
| ==Evidenziato== | `==Evidenziato==` |
| ~~Sbarrato~~ | `~~Sbarrato~~` |

## 📌 Titoli
| Visualizzazione (Risultato) | Scrittura (Cosa digitare) |
| :--- | :--- |
| **Titolo 1 (Materia)** | `# Titolo 1` |
| **Titolo 2 (Capitolo)** | `## Titolo 2` |
| **Titolo 3 (Paragrafo)** | `### Titolo 3` |
## 📋 Liste e Compiti
| Visualizzazione (Risultato) | Scrittura (Cosa digitare) |
| :--- | :--- |
| • Punto elenco | `- Punto elenco` |
| 1. Punto numerato | `1. Punto numerato` |
| 🔲 Compito da fare | `- [ ] Compito da fare` |
| ☑️ Compito finito | `- [x] Compito finito` |

## 🔗 Collegamenti e Media
| Visualizzazione (Risultato) | Scrittura (Cosa digitare) |
| :--- | :--- |
| Link a una nota | `[[Nome Nota]]` |
| Mostra PDF integrato | `![[Documento.pdf]]` |
| [Sito Web](https://google.com) | `[Sito Web](https://google.com)` |
